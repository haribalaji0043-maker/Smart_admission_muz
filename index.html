ℹ️ About Project

Smart Admission Decision using Multiplexer Logic

Problem Statement

Admission offices must combine several eligibility criteria into a single, explainable decision. This project demonstrates that a 4:1 multiplexer — a core Digital Fundamentals concept — can serve as the actual decision-making mechanism.

Objective

Design a software solution for a real-world admission scenario using a specified digital-system concept (the MUX) and reproducible synthetic data, with full traceability from candidate criteria through to the final decision.

Why MUX?

A MUX is the simplest circuit that "chooses" an output from several inputs based on a control signal — a direct hardware analogue of an admissions office choosing which eligibility path applies to a candidate.

Technology Stack

HTML5, CSS3, and vanilla JavaScript only — no frameworks, no build step, no backend. Runs from any static file server.

Testing

15 automated test cases (10 normal + 5 edge/fault) executed live in the Test Lab against the real MUX engine.

Future Improvements

An 8:1 MUX tier for finer-grained criteria, exportable audit logs per candidate, and a visual policy builder.
